# C$

El PEOR lenguaje de programacion de la familia **C**  

## Que es C$?

**C$** (pronunciado C Karl) es un `lenguaje de programación hecho en HTML` diseñado para no ser pensado para ser mejor si no para ser el PEOR, ya se que suena raro XD pero es EN SERIO y aparte, esta en ingles

## Ejemplo C$

```c$
#include <karl.h>$
// Karl's first program. Do not disappoint him.
moolah x = 10$
moolah y = 32$
word name = "Karl"$

yell("Hello, " + name + "!")$
yell("x + y =", x + y)$

karl add(a, b) {
  give a + b$
}$

yell("add(3, 4) =", add(3, 4))$

moolah i = 0$
again (i < 3) {
  yell("loop number", i)$
  i = i + 1$
}$

maybe (x > 5) {
  yell("x is big. Karl approves.")$
} otherwise {
  yell("x is small. Karl is disappointed.")$
}$

```
